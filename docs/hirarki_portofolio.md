IWWI

IWWI is a comprehensive maintenance management application designed for industrial facilities. It offers a

sophisticated input form for detailed equipment registration, a robust monitoring dashboard to track machine
performance, and a convenient QR code scanning feature for quick identification of assets.

Key features include:

  Advanced Equipment Registration: Capture essential information about your industrial machinery, including

specifications, maintenance schedules, and critical components.

  Real-time Monitoring Dashboard: Visualize machine status, performance metrics, and potential issues in a

centralized dashboard for efficient oversight.

  QR Code Scanning: Quickly access detailed equipment records by simply scanning the unique QR code affixed

to each machine.

IWWI empowers businesses to streamline maintenance operations, optimize resource allocation, and ensure the
reliability of their industrial equipment.

Skills: Kotlin, Firebase, Version Control
